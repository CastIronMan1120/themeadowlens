---
name: Publishing Pipeline
description: Staging and publishing rules for new artworks.
---
All bulk photo uploads and automated ingestion scripts MUST create documents as drafts (using `_id: "drafts.<uuid>"`).
This safely quarantines them from the live production site.
Photos must never go live without an assigned Category/Venue.
Uncategorized staging photos are to be managed and published using the custom Bulk Categorizer React plugin inside the Studio.


- The Sanity Studio's Bulk Categorizer is the definitive 'Warehouse' tool. It must natively support Bulk Uploading, Bulk Deleting, and Duplicate File Detection so the user does not need to run developer terminal scripts to manage staging photos.
- **Automatic Caption & Title Derivation on Upload:** Whenever photos are uploaded (via Studio or script), automatically derive `title`, `displayTitle`, and `caption` (and `species` for biological subjects) by pulling the text from the front of the filename up to, but not including, the 2-digit year prefix (`^(.+?)\s+(\d{2})-[A-Za-z0-9]`, e.g., `American Goldfinch 24-PA031058 Edit.jpg` -> `American Goldfinch`), while storing the raw filename in `fileName`.
- **Automatic Canonical `species` & Unique `seo` Tagging Across All Lifecycles:** Never require the admin to manually type the `species` field or `seo` metadata in the SEO detail screen. `species` (stripped of parenthetical modifiers like `(immature)`, `(male)`, `(female)`, `(juvenile)` and normalized to Title Case) and unique `seo` (`metaTitle`, `metaDescription`, `keywords`) must be derived and populated automatically across all lifecycles: (1) Photo Upload (`handleUpload`), (2) Warehouse Move/Copy (`handleMoveTo` / `handleCopyTo`), (3) Opening the `✨ Optimize / Edit` modal, and (4) Clicking `✨ 1-Click Auto-Optimize Photo & SEO` (`handleAutoOptimizeArtwork`).
- **No Duplicated Photos on Root Venue Pages:** Root Venue pages (`/category/[slug]`) that have Sub-Venues must only display their Sub-Venue directory tiles and never render the individual photos belonging to their Sub-Venues.
- **Complete Add, Rename & Slug Overwrite Cycle for Venues/Sub-Venues:** Custom Sanity Desk views (`VenuePhotoGridPane`) and modals must auto-sync `slug` and `seo` (`metaTitle`, `metaDescription`, `keywords`) whenever a Venue or Sub-Venue title is entered or renamed (unless manually overridden), allow unrestricted manual slug overwriting in the `URL Slug` field, and atomically update the published document while deleting any stale `drafts.<id>` category document on save.
- **Scroll-Stable Navigation Header:** Never shrink the in-flow layout height of a `sticky` header on scroll without a constant-height outer `<header>` wrapper and scroll hysteresis (`scrollY > 80` to compact, `scrollY < 20` to expand), and never use `transition-all` to animate `font-size` on scroll.
- **Original Filename Preservation & Display (`fileName` & `image.asset->originalFilename`):** Every artwork must retain its complete original filename (including species name, 2-digit year, camera frame number, edit version suffix, and file extension, e.g., `American Goldfinch 24-PA031058 Edit.jpg`) in `fileName` (falling back to `image.asset->originalFilename`). The full original filename must always be visible and copyable inside the Admin Photo SEO Detail Modal (`✨ Optimize / Edit`) and on Admin grid cards so the photographer can trace the exact processing version and date.
- **Per-Venue Duplicate Filename Prevention:** Never allow two artworks with the same normalized original filename (`fileName` / `image.asset->originalFilename`) to be uploaded, moved (`handleMoveTo`), copied (`handleCopyTo`), or reassigned (`handleSaveArtworkDetails`) into the **same** Venue or Sub-Venue. Copies of the same photograph ARE permitted across *different* Venues/Sub-Venues (for example, a bird photo appearing in both `Warblers` and `Splishes, Splashes and Reflections`), but never twice within the same Venue/Sub-Venue.
- **Admin Warehouse Hover Magnification:** Photo cards in `VenueGridManager.jsx` (`Unassigned Warehouse` and Venue grids) must provide high-resolution (`?w=1800`) cursor-tracking hover magnification (`2.6x` optical loupe) and a 1-click full-screen inspection overlay so the photographer can inspect focus, feather detail, and composition before assigning photos to a Sub-Venue.
- **Per-Venue Alphabetical Species Sorting (`alphabetizeBySpecies`):** Categories/Sub-Venues support an optional `alphabetizeBySpecies` boolean toggle inside the Admin Venue Edit/Rename modal. When enabled on a Sub-Venue (such as `Warblers`), both the frontend gallery (`/category/[...slug]`) and the artwork page-turn navigation (`/art/[slug]`) sort artworks alphabetically (`A–Z`) by `species || displayTitle || title` so multi-species galleries group all photos of each species together in order.
- **Cinematic Picture-Book Artwork View (`/art/[slug]`):** Individual artwork pages must present the photograph immediately in a full-viewport cinematic picture-book stage (`~80vh–85vh` height, full gallery width, `2400px` resolution) with left/right page-turn navigation arrows and the artwork title visible immediately below the image without requiring clicks to upsize.
- **Row-Major Left-to-Right Gallery Grid (`Gallery.jsx`):** Always use a row-major CSS Grid (`grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 xl:grid-cols-4 gap-6 sm:gap-8 items-start`) rather than CSS multi-column masonry (`columns-*`) so that when `alphabetizeBySpecies` is enabled on a Venue or Sub-Venue, the photo thumbnails read alphabetically (`A–Z`) from left to right across each row.
- **Custom Root & Sub-Venue Tile Ordering (`sortOrder`):** Root Venues on the homepage and Sub-Venues on category pages must query `| order(coalesce(sortOrder, 9999) asc, title asc)` and allow custom ordering inside `VenueGridManager.jsx`.
- **Homepage Right Panel Static Photo & Bio Overlay Toggle (`rightPanelImage` & `showWelcomeOverlay`):** The homepage right-hand `16:9` panel must allow uploading/selecting a static photograph (`rightPanelImage`) and toggling the Welcome/Bio text overlay (`showWelcomeOverlay`) on or off via a checkbox in both `Homepage Settings` and `VenueGridManager.jsx`.
- **Header & Footer Brand Identity (`Navigation.jsx` & `Footer.jsx`):**
  - Color `"The"` white (`#FFFFFF`), `"Meadow"` sage marsh green (`#9AB17A`), and `"Lens"` dusk gold (`#F7C873`) in both the top header and footer logos.
  - Align the right-hand desktop navigation menu with the bottom baseline of `"The Meadow Lens"` title, separated from the slogan below by a full-width `6pt` (`6px`) light gray line.
  - Display the tightened, wider-tracked 2-line `"Wow Factor"` slogan followed beneath by `[Explore The Venues]` (`/#venues`), `[Meet David]` (`/artist`), and a camera shutter-blade aperture icon.
- **Mobile-First Responsiveness & `themeadowlens-app-green.vercel.app` Verification:**
  - Always alias every Vercel deployment to `https://themeadowlens-app-green.vercel.app/` and verify mobile (`390×844`) and desktop responsiveness live in the browser before domain cutover.
  - **Visualize in Room (`WallPreviewStudio.jsx` & `ArtworkOptions.jsx`):** Always render `Visualize in Room` and `Inquire About This Piece` as direct, first-class buttons on `/art/[slug]` (and support `?visualize=true` from `ArtworkCard.jsx` `Room View` buttons). Full-screen modals must use `h-[100dvh]` with locked body scroll, a prominent `Close ×` pill button, proportional mobile frame borders (`border-[3px] sm:border-[6px] md:border-[10px]`), quick print-size presets (`24"`–`60"`), and visual wall-paint color swatches.
  - **Mobile Header & Welcome Overlay (`Navigation.jsx` & `page.js`):** Ensure zero horizontal overflow (`document.documentElement.scrollWidth <= window.innerWidth`) on `360px–430px` smartphones and keep the translucent Welcome card centered inside the `16:9` Right Panel across mobile, tablet, and desktop viewports.
