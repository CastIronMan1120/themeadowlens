# The Meadow Lens: Operational Rules

When operating within this specific workspace and deploying to Vercel, you MUST adhere to the following rules to prevent deployment failures, infinite hangs, file corruption, and authentication roadblocks.

## 1. Vercel Framework Detection Bug
Vercel fails to automatically detect this project as a Next.js application when deployed via the CLI from this environment, resulting in a `dist` directory error. 
*   **The Fix:** You must ensure `vercel.json` exists in the root directory with the exact configuration: `{"framework": "nextjs"}`.

## 2. Vercel Alias Hijacking
When `themeadowlens.com` is attached to the Vercel project, Vercel will stop automatically aliasing CLI deployments to the staging URL (`themeadowlens-app-green.vercel.app`).
*   **The Fix:** If the user cannot see the latest deployment on the staging URL, you must manually run: `npx vercel alias set <auto-generated-deployment-url> themeadowlens-app-green.vercel.app` to force the alias.

## 3. GitHub Authentication Hangs (Windows)
Do NOT run `git push origin main` as an unattended background task. The Windows Git Credential Manager will trigger an invisible GUI popup on the user's desktop requesting authentication, causing the automated terminal to hang indefinitely.
*   **The Fix:** Instruct the user to run `git push origin main` themselves, OR ask them to look at their taskbar to approve the authentication popup while your command runs.

## 4. PowerShell File Encoding Corruption
Do NOT use PowerShell shell redirection (`echo "text" >> file.md`) to write or append to files. PowerShell defaults to UTF-16 LE with BOM, which permanently corrupts JSON and Markdown files.
*   **The Fix:** Exclusively use the native AI tools (`write_to_file`, `replace_file_content`) to edit code and markdown.

## 5. Sanity CMS Authentication Lockouts
If the user attempts to log into the embedded Sanity Studio (`/studio`) or `sanity.io/manage` and receives a "You have no projects" or "Access Denied" error, do NOT attempt to recreate the project or assume the database was deleted.
*   **The Cause:** Sanity is strictly locked to the exact OAuth provider (Google/GitHub) and email address used during creation. Browsers often auto-login with a different default email.
*   **The Fix:** Instruct the user to log out of `sanity.io/manage` entirely and systematically attempt to log in using their other Google or GitHub accounts until the `themeadowlens` project ID (`h7ncr8cq`) appears.
